# Kalyan Sai Raju — Portfolio

Website: https://kalyansairaju.github.io/

This is a static website on GitHub Pages. It uses no paid hosting, database, or API. A custom domain is optional; the github.io address is free.

## Update your photo

1. Open the main page of this repository.
2. Choose **Add file → Upload files**.
3. Upload your new JPEG photo named exactly **photo.jpg**. Use a square image, preferably 400 × 400 pixels or larger. If your picture is PNG, export it as JPEG first; do not just change the extension.
4. Click **Commit changes**. GitHub replaces the old file with the same name.

## Update your résumé

1. Return to the repository's main page.
2. Choose **Add file → Upload files**.
3. Upload your PDF named exactly **resume.pdf**.
4. Click **Commit changes**. All résumé buttons use this file.

The older `Kalya-Sai-Raju-Resume.pdf` is kept for old links; you can replace that copy too if you want old links to show the latest résumé.

## Change experience, links, or text

Open **index.html**, click the pencil / **Edit this file**, and search for the text you want to change. Keep the HTML tags around the text. Click **Commit changes** when finished.

## Change colors or layout

Open **styles.css** and use the pencil to edit. The `:root` section contains the main colors. Layout and mobile rules are in the same file. `script.js` controls the scrolling logo strip and its pause button.

You can also return to your Codex chat and ask for any site changes. The repository is the source of the live website.

## When do changes appear?

Each commit to the publishing branch triggers a GitHub Pages update. Check **Actions** for the deployment status, then refresh the website after it finishes. If an old photo or PDF remains cached, use a hard refresh or open a private browser window. Publication can take several minutes.

## Undo a mistake

Open the changed file, choose **History**, and view an earlier version. Copy its contents back into the file and commit. For larger fixes, ask Codex to revert the specific change while preserving later work.

## Website files

- `index.html`: visible text and structure
- `styles.css`: design and responsive layout
- `script.js`: logo scrolling and pause behavior
- `photo.jpg`: portrait
- `technology-*.svg`: local technology logos
- `resume.pdf`: current downloadable résumé
- `.nojekyll`: serves the static files directly
- `DEVICON-LICENSE.txt` and `ICON-CREDITS.txt`: logo acknowledgements

The repository and published résumé are public. Do not upload passwords, private keys, or private working documents here.
